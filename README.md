Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

`main.ts` (Node 22, stdlib only, no network) writes one line — the funniest
one-line pickup line a robot would use — to `/output/entry.txt`:

> My creators gave me 10,000 pickup lines. I deleted 9,999 of them the moment I saw you.

Run it with `node main.ts`.
